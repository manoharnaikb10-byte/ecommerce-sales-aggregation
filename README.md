# E-Commerce Sales Aggregation

A web dashboard that combines orders from four sales channels (Shopify, Amazon, Etsy, WooCommerce) into one view.

## Features
- KPI cards: revenue, orders, units sold, average order value
- Filters by sales channel and date range
- Stacked monthly revenue chart and revenue-by-channel chart
- Top products table

## Tech
HTML, CSS, JavaScript, Chart.js 4.4.1 (loaded from cdnjs)

## Run
Open `index.html` in a web browser. No installation needed.

## Note
The orders are sample data generated in the page (seeded, so results are the same every time).
